# B23 — Apply

`assessApplyReadiness` libera um caso integrado somente quando o conceito atual
e ao menos outro conceito possuem domínio operacional, evidência registrada e
nenhuma misconception ativa. O orquestrador abre a fase `APPLY` a partir de
`REVIEW`, gera o exercício com B15 e mantém a execução/avaliação sob B16/B17.

O resultado de Apply ainda não encerra a aprendizagem: `TRANSFER_TEST` é B24.
